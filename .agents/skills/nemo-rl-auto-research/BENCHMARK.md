# nemo-rl-auto-research Benchmark

Quick reference for evaluating the nemo-rl-auto-research skill.

## What we track
- Research quality: factual accuracy, source diversity, recency
- Depth: how many hops the agent goes vs. surface-level
- Speed: time to useful answer

## Quick checks
1. Ask a hard recency question (e.g. "what changed in X this month")
2. Ask a multi-hop "why" question
3. Ask for a comparison across 3+ options

## Known gaps
- Very niche academic topics may be thin
- Real-time data needs web access
